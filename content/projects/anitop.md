# AniTop

Каталог аниме: находишь тайтл, смотришь описание и список эпизодов, отмечаешь
то, к чему хочешь вернуться.

![Главный экран AniTop](projects/anitop.webp)

## Что умеет

- Поиск по каталогу с подсказками на лету
- Карточка тайтла: описание, жанры, статус, список эпизодов
- Избранное, которое переживает перезагрузку страницы
- Тёмная тема по умолчанию, светлая по желанию системы

## Данные

Два источника, потому что ни один не закрывает задачу целиком:

| Источник | Зачем |
|---|---|
| Jikan API | Каталог, поиск, метаданные тайтлов |
| Yummy API | Эпизоды и то, чего нет в Jikan |

Ответы кэшируются на клиенте: у публичного Jikan есть лимит запросов, и без
кэша поиск на каждое нажатие клавиши упирался бы в 429.

## Стек

- **Vue 3** с Composition API
- **TypeScript** на типах ответов API
- **Vite** как сборщик и dev-сервер
- **Bootstrap** для сетки и базовых компонентов
- **Cloudflare** как хостинг и CDN
