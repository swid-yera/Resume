# Portfolio

Сайт, в котором вы сейчас находитесь. Портфолио, притворяющееся настольной
системой: окна двигаются и меняют размер, у файлов есть пути, а у терминала -
своя файловая система.

![Рабочий стол Portfolio](projects/portfolio-os.webp)

## Что умеет

- Окна: перетаскивание, ресайз за любой край и угол, сворачивание, фокус
- Проводник: диск, дерево папок, адресная строка, сортировка по колонкам
- Терминал: `cd`, `dir`, `ls`, `cat`, `mkdir`, `history`, вкладки и автодополнение
- Браузер: открывает и файлы с диска, и внешние сайты
- Ридер markdown: оглавление, режим исходника, счётчик слов
- Телефон: окна на весь экран, свой док, кнопка «назад» закрывает верхнее окно

Проекты не хардкожены: каждый - обычный `.md`-файл, который одновременно и
плитка в папке Projects, и документ в ридере.

## Стек

JavaScript без фреймворков: в рантайме только `marked` и `dompurify`.
Хостинг GitHub Pages, домен и CDN на Cloudflare.

Логика, которую можно проверить без браузера, лежит отдельными модулями: 377
тестов на `node --test`.
