# Portfolio OS

Сайт, в котором вы сейчас находитесь. Портфолио, притворяющееся настольной
системой: окна двигаются и меняют размер, у меню есть подменю, у файлов - пути,
а у терминала - настоящая файловая система.

![Рабочий стол Portfolio OS](projects/portfolio-os.webp)

## Из чего состоит

- **Оконный менеджер** - перетаскивание, ресайз за восемь ручек, сворачивание,
  зум, z-порядок и фокус
- **Проводник** - диски, дерево папок, адресная строка, сортируемые колонки
- **Терминал** `jjsh` - `dir`, `cd`, `type`, `tree`, `echo >`, `start`
- **Браузер** - адресная строка понимает `file:///C:/...`, поиск по диску и
  внешние сайты во фрейме
- **Ридер markdown** - оглавление, режим исходника, счётчик слов
- **Меню-бар и контекстное меню** - собраны из одного примитива, набор пунктов
  зависит от активного окна

## Как устроено

Никаких фреймворков: модули ES, шаблонные строки вместо JSX и `localStorage`
вместо базы. Правило простое - вся логика, которую можно проверить без DOM,
живёт отдельным модулем со своим тестом на `node --test`.

```
js/
  fs.js              диски, пути, метаданные
  window-manager.js  окна
  ui/menu.js         примитив меню
  apps/              explorer, markdown, console, browser, projects...
```

> Проекты не лежат в базе и не хардкодятся в JS. Каждый проект - обычный
> `.md`-файл с фронтматтером, который одновременно и данные для плитки в папке
> Projects, и документ, открываемый в ридере.

## Стек

- **Vanilla JS** - ноль зависимостей в рантайме, кроме `marked` и `dompurify`
- **Vite** - сборка и dev-сервер
- **GitHub Actions** - деплой на GitHub Pages по пушу в `main`
